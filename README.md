# AI Note Organizer（AI 笔记整理）

一个 Obsidian 插件：用 DeepSeek / 硅基流动等 **OpenAI 兼容接口**，智能地把笔记**分类整理**——自动移动进合适的文件夹，并在 frontmatter 里补充分类标签。

## 功能

- 多种整理范围：**当前笔记** / **指定文件夹** / **整个库**，还可在文件列表里**右键多选**整理（文件夹右键也可）
- **先预览再应用**：每篇笔记可修改目标文件夹、取消勾选跳过，确认后才真正改动
- **文件夹 + 标签**同时整理
- **撤销上次整理**：一键回退最近的移动和标签改动
- **自动写摘要**：为笔记 frontmatter 生成一句中文摘要（`summary` 字段），支持当前笔记 / 多选 / 文件夹
- **批量重命名标题**：AI 按内容起规范中文标题，预览可改/可跳过后应用
- **自动补双链**：AI 找出内容相关的笔记，在末尾写入「相关笔记」小节并插入 `[[链接]]`
- **生成 MOC 索引页**：给文件夹生成按主题分组的目录页，汇总子笔记链接和说明
- **AI 问答面板**：侧边栏聊天框，检索库中相关笔记后回答你的问题（回答以 Markdown 富文本呈现）
- **可视化仪表盘**：侧边栏「库概览」——笔记总数、文件夹分布条形图、标签云、最近修改、一键整理入口
- **更美观的界面**：整理预览按目标文件夹分组上色、彩色标签 chips
- **自定义分类体系**：在设置里指定顶层文件夹，AI 只按你给的分类整理（可选）
- **闪卡 + 间隔重复复习**：AI 生成 / 手动添加闪卡，卡片管理（编辑/删除），按 SM-2 记忆曲线安排复习，可视化翻卡复习
- **AI 写作助手**：选中文字即可润色 / 扩写 / 缩写 / 翻译，或在光标处续写
- **知识回顾 / 周报**：一键生成最近 7/14/30 天的笔记回顾报告（按主题分组 + 建议）
- 支持任意 OpenAI 兼容接口（DeepSeek、硅基流动、OpenAI、Moonshot 等），内置 DeepSeek / 硅基流动预设

## 安装

1. 构建出 `main.js`（见下方「从源码构建」），或直接使用已构建好的文件
2. 把本文件夹 `ai-note-organizer` 复制到你的库目录 `<vault>/.obsidian/plugins/` 下
3. 重启 Obsidian，在「设置 → 第三方插件」里启用「AI Note Organizer」
4. 打开「设置 → AI 笔记整理」，选择服务商并填写 API Key

## 从源码构建

需要安装 Node.js（≥ 18）：

```bash
npm install
npm run build   # 生成 main.js
```

## 使用

1. 任选一种方式触发：
   - 命令面板（`Ctrl/Cmd + P`）里搜索「整理」：整理当前笔记 / 整理指定文件夹… / 整理整个库
   - 在左侧文件列表里选中一篇或多篇笔记 → 右键 →「AI 整理…」
   - 右键某个文件夹 →「AI 整理此文件夹」
   - 需要回退时用「撤销上次整理」
   - 生成摘要：命令面板「为当前笔记生成摘要」，或右键笔记/文件夹 →「AI 生成摘要」
   - 重命名标题：命令面板「为当前笔记重命名（AI 起标题）」，或右键笔记/文件夹 →「AI 重命名」
   - 添加相关链接：命令面板「为当前笔记添加相关链接」，或右键笔记/文件夹 →「AI 添加相关链接」
   - 生成 MOC：命令面板「生成 MOC 索引页…」，或右键文件夹 →「AI 生成 MOC 索引页」
   - AI 问答：点击边栏「AI 问答」图标，或命令面板「打开 AI 问答面板」
   - 库概览：点击边栏「库概览」图标，或命令面板「打开库概览」
   - 闪卡：右键笔记/文件夹 →「AI 生成闪卡」；左侧「闪卡」图标打开闪卡页面（添加 / 管理 / 复习）
   - AI 写作：选中文字后右键 →「AI 改写 / 续写…」，或命令面板搜索
   - 知识回顾：命令面板「生成知识回顾」，或仪表盘「生成知识回顾」按钮
2. 插件会读取笔记内容，调用你配置的模型判断分类，弹出预览
3. 勾选要处理的笔记，点击「应用」；不满意可用「撤销上次整理」一键回退

## 说明

- API Key 会**明文**保存在 `.obsidian/plugins/ai-note-organizer/data.json`，请勿分享该文件
- 按模型用量计费；整理整个库前，建议先在一个小文件夹上试一次
- 移动文件会自动更新 Obsidian 里的双向链接
